# ServiceNow Incident – Client Script & UI Policy

## Project Overview

This project implements Client Scripts and UI Policies on the ServiceNow Incident table to improve user experience, enforce field behavior, and reduce incorrect data entry.

## Implemented Tasks

### 1. UI Policy

Created a UI Policy on the Incident table to control field behavior based on incident conditions.

### 2. UI Policy Action – Urgency

Configured a UI Policy Action to dynamically control the Urgency field.

### 3. onChange Client Script

Created an onChange Client Script to perform actions dynamically when a field value changes.

## Technologies Used

* ServiceNow
* JavaScript
* Client Scripts
* UI Policies
